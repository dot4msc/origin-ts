# dot4-game-engine
# 12-Month Roadmap for Building a 2D Game Engine

A structured, beginner-friendly plan for creating a full 2D pixel-art game engine over one year.

---

## 📚 Recommended Books

* **Game Programming Patterns** — Robert Nystrom (Best starting point)
* **Game Engine Architecture** — Jason Gregory
* **Game Coding Complete** — Mike McShaffry
* **The Nature of Code** — Dan Shiffman
* **Programming 2D Games** — Charles Kelly
* **Real-Time Collision Detection** — Christer Ericson (advanced)

---

## 🗓️ Overview by Month

### **Months 1–2: Foundations**

**Goal:** Learn core concepts and implement the basic engine loop.

#### Learn

* Canvas API, drawImage()
* requestAnimationFrame & delta time
* TypeScript classes
* Asset loading

#### Build

* `Game` class
* `Scene` class
* `Sprite` class
* Input manager (keyboard & mouse)

#### Result

A sprite moves with arrow keys.

---

### **Months 3–4: Animation & Tilemaps**

**Goal:** Make the engine usable for 2D game creation.

#### Learn

* Sprite sheets & animations
* Tilesets and JSON tilemaps
* Layer-based drawing

#### Build

* `Animation` system
* `Tilemap` renderer

#### Result

Player walking on a tilemap.
